問題ID: 545「きょうの ごきげんは いかが？」

チャンココさん、おしかったですね！いっしょに かくにんしましょう。

この英語は、あいてに「元気？」ときくときの まほうの言葉です。

  • How（ハウ）：これは「どんなかんじ？」とようすをきく言葉です。
  • are you（アー ユー）：これは「あなたは〜ですか？」ですね。
  • today（トゥデイ）：これは「きょう」という意味です。

ぜんぶあわせると、「きょうの あなたは どんなかんじ？」つまり「きょうは どうですか？」になります。

【もっと知っちゃおう！】
お友だちにきくときは、もっとみじかく "How are you?" だけでもOKだよ！
「ハウ アー ユー？」ってリズムよく言ってみてね！

問題ID: 672「禁止を伝える表現」

へーさん、惜しかったですね！文の構造を整理してみましょう。

この文は「〜しないで」という否定の命令文です。ポイントは以下の2点です。

  • Don't（ドント）を使う： 相手に何かを禁止するときは、文の頭に Don't を置きます。
  • 動詞の原形： Don't の後ろには必ず動詞の原形（もとの形）を置きます。今回は「走る」という意味の run が使われていますね。

もし、もっと丁寧に「ここで走らないでください」と言いたい場合は、文の最初か最後に Please をつけて、
"Please don't run here." とすることもできます。

【ステップアップ・アドバイス】
「ここでは走るな！」と強く言いたい時は "No running here." という掲示板のような表現もあります。まずは基本の Don't + 動詞の原形 を完璧にマスターしましょう！

問題ID: 953「readの過去形に注目」

みきさん、惜しかったですね！ちょっとした「ひっかけ」にハマってしまったかもしれません。

この文のポイントは、動詞 read の性質です。論理的に整理しましょう。

  1. 形が変わらない過去形： 「読む」という動詞は、現在形も過去形もスペルは同じ read です。
  2. 発音の変化： スペルは同じですが、発音が変わります。現在形は「リード」、過去形は赤色のredと同じ「レッド」と読みます。
  3. 三単現のsがない： もしこれが「（ふだん）アサコは魔法の本を読みます」という現在形なら、主語がAsako（三人称単数）なので reads となるはずです。sがついていないということは、これは過去形（読みました）だと判断できます。

和訳が「読みました」となっているので、過去の意味を持つ read（レッド） を使うのが正解です。英語はスペルが同じで役割が違う単語があるので、文脈で見分けるのがコツですよ！

問題ID: 1350「モノを渡す時の語順」

みきさん、惜しかったですね！「誰に何を」の語順は、英語を学び直す際につまずきやすいポイントです。

「gave（与えた）」のような動詞を使うとき、語順には2つのパターンがあります。

  • パターンA： She gave me it.（誰々に・何を）
  • パターンB： She gave it to me.（何を・誰々に）

今回の問題はパターンBです。「モノ(it)」を先に持ってくる場合は、後ろに「to（〜へ）」が必要になります。プレゼントが自分の方へ向かってくる矢印をイメージすると覚えやすいですよ。

※ちなみに、代名詞（itやthem）を「モノ」として使う場合は、今回の "gave it to me" という形にするのが一般的で自然な響きになります。

問題ID: 1392「前置詞 for の役割」

みきさん、惜しかったですね！少し難しい語彙が出てきましたが、構造はシンプルです。

ここでのポイントは、voted for というセット表現です。

  • vote： 「投票する」という動詞です。
  • for： 「〜に賛成して」「〜のために」という方向性を表します。
  • the bill： 「法案」という意味です。（お会計の「請求書」と同じ単語ですが、政治の文脈では法案になります）

vote for 〜 で「〜に（賛成の）投票をする」という意味になります。逆に反対票を投じる場合は vote against 〜 と言います。セットで覚えておくと、ニュースなども理解しやすくなりますよ！

問題ID: 2109「すき！をつたえよう」

チャンココさん、惜しかったですね！でも大丈夫、とってもシンプルな文ですよ。

英語は、話す順番がとっても大切なんです。この文は「だれが」「どうする」「何を」の順番でならんでいます。

  • I（アイ）：わたしは
  • like（ライク）：すきです
  • it（イット）：それを

この3つをガッチャンコさせると、「わたしは それが すきです」になります！

【やってみて！】
"it" をほかの言葉にかえるだけで、いろんな「すき」が言えるよ！
・I like apples.（りんごがすき）
・I like sushi.（おすしがすき）
チャンココさんは何がすきかな？
